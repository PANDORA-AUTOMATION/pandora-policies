PANDORA Personnel Verify.

PANDORA uses Roblox OAuth 2.0 to confirm a user's Roblox identity before personnel applications and other account-linked actions are processed.

Sign in with Roblox

Roblox reviewers can use this entry point to test the complete authorization flow without joining the PANDORA Discord server. The review flow authenticates the Roblox account but does not link it to a Discord user or store it as a personnel verification.
